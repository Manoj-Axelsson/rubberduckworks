# Methodology

This directory contains the systematic approaches, processes, and methodologies that RubberDuckWorks uses to explore, understand, and build systems.

## Purpose

Methodology documents define how we work: the disciplines, practices, and workflows that make RubberDuckWorks effective.

## Core Methodology

Our approach follows the RubberDuckWorks Method:

```
Reality → Understanding → Documentation → Models → Architecture → Data → Code → Measurement → Improvement
```

Nothing skips a stage.
